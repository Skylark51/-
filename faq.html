플레이 중 자주 찾는 답변

저장 위치, 모바일 입력, 화면 설정, 광고 준비 상태처럼 게임 이용에 필요한 내용을 정리했습니다.

게임으로 돌아가기
기록은 어디에 저장되나요?
점수, 장독대별 통계, 설정, 진행 중인 게임은 현재 브라우저의 localStorage에 저장됩니다. 다른 브라우저나 기기로 자동 동기화되지는 않습니다.
모바일 키패드가 보이지 않아요.
문제 형식에 맞는 키패드가 화면에 표시됩니다. 지원하지 않는 특수 입력은 기본 입력칸과 브라우저 키보드를 사용하도록 유지됩니다. 화면을 회전했거나 주소창 높이가 바뀌어도 게임 화면은 현재 viewport에 맞춰 다시 배치됩니다.
게임을 처음부터 시작하려면 어떻게 하나요?
모바일 하단 도구 모음 또는 PC의 게임 도구에서 새로 시작을 선택한 뒤 확인하세요. 브라우저 전체 기록을 지우려면 브라우저의 사이트 데이터 관리 기능을 사용해야 합니다.
소리와 애니메이션은 바꿀 수 있나요?
로비 설정에서 소리와 애니메이션 설정을 조절할 수 있습니다. 운영체제의 동작 줄이기 설정도 게임 효과에 반영됩니다.
광고가 표시되나요?
현재 배포 구성에서는 광고 로딩이 비활성화되어 있습니다. 실제 publisher ID와 동의 관리가 준비되기 전에는 광고 쿠키와 광고 스크립트를 요청하지 않습니다.
오류는 어디에 신고하나요?
문의 페이지의 GitHub 이슈 링크를 이용해 재현 절차, 기기, 브라우저, 화면을 알려 주세요.
