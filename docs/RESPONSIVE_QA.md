# 반응형 QA

## 정적 검증 대상

- PC: 1280×720, 1366×768, 1440×900, 1920×1080
- 모바일: 320×568, 360×640, 375×667, 390×844, 412×915, 768×1024
- 모바일 가로 방향

## 확인 항목

- 로비 하단 메뉴는 홈·장독대·기록 화면을 hidden 전환하며 앵커 스크롤을 사용하지 않는다.
- URL `?view=jars`, `?view=records`와 브라우저 뒤로가기를 지원한다.
- 760px 이하에서 로비 카드와 기록 대시보드는 1열이 된다.
- 상점은 980px 이하에서 미리보기와 상품 목록이 세로 배치된다.
- 게임의 기존 `visualViewport`, safe-area, 3열 숫자 키패드 규칙은 제거하지 않았다.
- 공통 버튼은 최소 44px 이상을 유지한다.
- `prefers-reduced-motion`에서 화면 전환과 애니메이션 시간이 사실상 0으로 축소된다.

## 브라우저 육안 검수가 필요한 항목

현재 실행 환경에서는 실제 iPhone Safari 주소창 접힘·펼침과 GPU 합성 결과를 직접 캡처할 수 없다. 배포 후 다음을 확인해야 한다.

1. 320×568에서 문제와 키패드가 겹치지 않는지
2. Safari 화면 회전 후 장면 높이가 재계산되는지
3. 실사 PNG 아틀라스 생성 실패 시 기본 스프라이트가 보이는지
4. 비기본 스킨 장착 후 게임 재진입 시 SVG 렌더러로 전환되는지
