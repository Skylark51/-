# 모바일 한 화면 최적화 작업

## 수정한 파일

- `콩쥐야_줘때써.html`: 모바일 압축 헤더 컨테이너와 캐시 버전 갱신
- `assets/css/game.css`: 뷰포트 고정, 4구역 그리드, 장면/문제/키패드/overlay 반응형 규칙
- `assets/js/ui-effects.js`: 기존 HUD·피버 DOM의 모바일 이동/PC 복원, `game-active` 생명주기, 압축 버튼 연결
- `assets/js/mobile-keypad.js`: 브라우저 키보드를 열지 않는 읽기 전용 답안 표시, 숫자·부호·소수·선택형 키패드
- `assets/js/device-entry.js`: `visualViewport`, resize, orientation change 기반 실제 가시 높이 동기화
- `docs/MOBILE_ONE_SCREEN_WORK.md`: 본 작업 기록

게임 로직, 채점, 문항, 저장, 피버 계산 파일은 수정하지 않았다. 게임 제목은 `콩쥐야 줘때써 - 화학편`으로 유지했다.

## 모바일 화면 4구역 구조

1. 압축 HUD: 32px 상단 조작줄, 점수·콤보·물 1줄, 5px 피버 게이지
2. 게임 장면: 콩쥐는 왼쪽, 장독대와 구멍을 막는 두꺼비는 오른쪽에 모바일 크기로 재배치
3. 문제 영역: 짧은 유형명, 발문, 캡슐 타이머, 얇은 시간 게이지, 1~2줄 피드백
4. 입력 영역: 답안 표시와 전체 삭제, 4열 숫자/부호/소수 키 또는 2열 선택 버튼

모바일일 때 기존 `.game-hud`와 `.fever-panel`을 압축 HUD로 이동하고 PC로 전환하면 `.question-panel`의 원래 위치로 돌려놓는다. 따라서 기존 DOM ID와 게임 엔진 연동은 그대로다.

## 모바일에서 숨긴 PC용 요소

- 긴 게임 헤더와 브랜드 제목
- 장면 상태 카드, 누수 속도 카드, 캐릭터 이름
- 문제 유형 보조 배지와 별도 제한 시간 문구
- 상세 진행 카드, 목표 점수 문구, 기존 하단 모바일 버튼
- 피버 도움말 문장

숨긴 요소는 삭제하지 않아 기존 로직이 계속 값을 갱신할 수 있다.

## 높이별 미디어 쿼리

- 기본 모바일: 동적 뷰포트 안에서 HUD/장면/문제·입력 3행 그리드(문제 카드 내부에서 문제와 입력을 분리)
- `max-height: 700px`: 장면 비중과 여백 축소
- `max-height: 600px`: 헤더 30px, 장면 최소화, 타이머를 문제 우측에 겹치지 않게 절대 배치
- `max-width: 340px`: 320px 폭용 제목·캐릭터·장독대 위치 조정
- 가로 `orientation: landscape` + `max-height: 600px`: 왼쪽 장면/오른쪽 문제·입력 2열

## 주소창과 안전 영역

`100vh`, `100svh`, `100dvh` 순서의 fallback을 제공한다. `device-entry.js`가 `visualViewport.height`를 `--game-viewport-height`에 기록하고 resize 및 orientation change 때 갱신한다. 게임 셸은 `env(safe-area-inset-top)`과 `env(safe-area-inset-bottom)`을 적용해 홈 인디케이터와 노치 영역을 피한다.

게임 중 `html`과 `body`에 `game-active`를 적용해 body와 내부 핵심 패널의 overflow 및 overscroll을 차단한다. 게임 종료/클리어 때 클래스는 제거되며 결과 패널 자체는 고정 overlay로 유지된다.

## 테스트 결과

검사 대상 규격: 320×568, 360×640, 375×667, 390×844, 412×915 및 높이 600px 이하 가로 모드.

- CSS 구조 검증: 각 규격에서 고정 동적 뷰포트, `min-width: 0`, 내부 `overflow: hidden`, 48px 키와 52px 이상 주요 제출 영역 규칙 확인
- 320×568: 압축 헤더, 핵심 장면, 발문, 타이머, 답안 표시, 숫자 키, 제출 버튼을 한 화면 우선순위로 배치
- 390×844 및 412×915: 장면 비중을 확대하고 문제/입력 가독성 유지
- 세로: HUD/장면/문제·입력 순서 유지
- 가로: 장면/문제 2열, 키패드 내부 스크롤 제거
- 숫자·소수·부호형 및 `binary_choice`/`multiple_choice` 메타데이터 분기 확인
- `node --check` 3개 수정 모듈 통과
- `node --test`: 30개 전체 통과
- `git diff --check`: 통과

연결된 GUI 브라우저 자동화 채널을 사용할 수 없어 실제 iOS Safari/Android Chrome 기기 캡처는 수행하지 못했다. 배포 후 실기기에서 주소창 확대·축소와 제조사별 안전 영역을 한 번 더 확인하는 것을 권장한다.

## 남아 있는 문제

코드상 알려진 차단 문제는 없다. 실기기 브라우저별 폰트 렌더링 차이와 주소창 동작은 배포 후 최종 확인 대상이다.
