# 장독대 게임 재구축 보고서

## 변경

- 게임 HTML을 장면·HUD·문제·키패드 grid로 재작성
- 대형 인라인 모바일 보정 제거
- 게임 하단 툴바 제거
- 단일 SceneRenderer와 상태 머신 도입
- 4개 실제 핵심 포즈를 상태 원화로 정식 연결
- 가짜 60프레임 연결 제거
- 모바일 3열 키패드 고정
- `main.js` RAF를 running 상태에서만 예약
- `UIAdapter`가 바뀐 텍스트·폭만 갱신
- 구매 기록 보존 및 미지원 실사 스킨 상태 명시

## 실제 원화 수

독립 핵심 포즈는 4장이다. 60장의 연속 원화가 아니다.

## 유지

문항, 판정, 점수, 물 수치, 피버, 콤보, 업그레이드, 저장 데이터는 변경하지 않았다.

## 제한

스킨별 실사 원화가 없어 비기본 스킨은 기본 장면으로 표시된다. 실제 모바일 Safari 최종 육안 검수가 필요하다.
