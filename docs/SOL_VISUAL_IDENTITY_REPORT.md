# 시각 정체성 통합 보고서

## 적용 내용

- 한지·옹기·청자·물·금색을 공통 재료 언어로 정의했다.
- 로비를 홈·장독대·기록의 앱 화면으로 분리했다.
- 모바일 하단 내비게이션을 자동 스크롤에서 실제 화면 전환으로 변경했다.
- 로비 대표 장면은 게임의 기본 실사 PNG 자산을 재사용한다.
- 장독대 선택 카드는 월드 선택 화면처럼 보이도록 재구성했다.
- 상점과 게임 UI를 동일 토큰과 타이포그래피로 통일했다.
- 기본 실사 렌더러와 구매 스킨 렌더러의 충돌을 제거했다.
- 구매 스킨 장착 시 스프라이트 렌더러를 선택해 실제 외형이 보이도록 했다.

## 유지한 기능

- 화학 문항과 정답
- 점수·물·피버 규칙
- 저장 버전과 기존 데이터 의미
- 일일 미션, 연구소, 상점 구매·장착
- 실제 기록 기반 대시보드
- 모바일 3열 키패드와 `visualViewport` 계산

## 알려진 제한사항

기본 실사 애니메이션은 4개의 핵심 PNG 포즈를 보간해 60셀로 만든다. 60장의 독립 원화가 아니다. 비기본 스킨은 현재 SVG 스프라이트를 사용하므로 완전한 실사 통일은 추가 원화 제작이 필요하다. 이번 작업에서는 이 차이를 숨기지 않고 렌더러 규칙과 후속 자산 목록을 문서화했다.
