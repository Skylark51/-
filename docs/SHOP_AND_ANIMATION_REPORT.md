# 콩 상점·스킨·60단계 애니메이션 구현 보고서

## 적용 범위

- 모바일 문제 카드와 키패드 행을 분리하여 상호 겹침 방지
- PC·모바일 반응형 `shop.html` 추가
- 기존 게임 재화인 콩을 사용하는 구매 시스템 추가
- 구매 상품 자동 착용 및 다시 착용 기능 추가
- 실제 게임 화면에 장착 상태 적용
- 콩쥐, 두꺼비, 장독대, 바가지의 스킨 시스템 추가
- 콩쥐·두꺼비·물결·물줄기를 위한 60단계 절차형 애니메이션 타임라인 추가

## 상점 카테고리

1. 콩쥐 도구
   - 나무 바가지
   - 놋쇠 바가지
   - 청자 바가지
   - 월광 바가지
2. 콩쥐 옷
   - 고전 홍색 한복
   - 청람 학자복
   - 들녘 작업복
   - 야화 궁중복
3. 두꺼비 스킨
   - 논두렁 두꺼비
   - 황금 야근 두꺼비
   - 비취 수문장
   - 별밤 두꺼비
4. 장독대 스킨
   - 전통 옹기
   - 운학 청자
   - 달항아리
   - 흑칠 야광 항아리

총 16개 상품이며 카테고리마다 기본 지급 상품 1개를 포함한다.

## 저장 구조

- 기존 콩 잔액: `kongjuiya-chem-save`
- 상점 보유·착용 데이터: `kongjuiya-cosmetics-v1`

구매 시 기존 콩 잔액에서 가격을 차감하고, 보유 목록과 현재 착용 상태를 저장한다. 구매가 완료되면 해당 상품을 즉시 착용한다. 저장 실패 시 콩과 보유 데이터를 이전 상태로 되돌린다.

현재 별도의 로그인 서버가 없으므로 데이터는 브라우저 localStorage에 저장된다. 동일 브라우저에서는 PC·모바일 레이아웃 전환과 관계없이 유지되지만 서로 다른 기기 간 자동 동기화는 지원하지 않는다.

## 게임 적용 방식

게임 루트 요소에 다음 속성을 설정한다.

- `data-tool-skin`
- `data-kongjwi-outfit`
- `data-toad-skin`
- `data-jar-skin`

`assets/css/cosmetics.css`가 해당 속성을 읽어 바가지 재질, 콩쥐 의상 색과 문양, 두꺼비 색상과 광택, 장독대 재질과 문양을 변경한다.

현재 스킨은 기존 원화를 유지하면서 CSS 색상·문양·광택 레이어를 적용하는 방식이다. 각각의 의상을 별도로 그린 60장짜리 원화 스프라이트 시트는 포함하지 않는다.

## 60단계 애니메이션

`assets/js/animation-system.js`에 다음 배열이 각각 60개 프레임으로 정의된다.

- `IDLE_FRAMES`
- `POUR_FRAMES`
- `HIT_FRAMES`

`requestAnimationFrame`으로 현재 프레임을 선택하고 CSS 변수에 다음 값을 전달한다.

- 콩쥐 상하 이동과 회전
- 두꺼비 호흡, 눌림, 반동
- 장독대 수면의 높이와 폭 변화
- 물줄기 길이, 굵기, 각도, 투명도

정답 이벤트에서는 60단계 물 붓기 타임라인을 실행하고, 오답·시간 초과·타격 이벤트에서는 60단계 두꺼비 반동 타임라인을 실행한다. 모션 감소 설정 또는 `prefers-reduced-motion`에서는 애니메이션을 비활성화한다.

## 모바일 겹침 수정

세로 모바일 화면에서 문제 카드와 키패드를 다음 두 행으로 완전히 분리했다.

1. 문제 진행률·발문·한 줄 피드백
2. 입력 표시·숫자 또는 선택 키패드

문제 카드에는 `overflow:hidden`, 키패드 도크에는 독립 높이와 내부 그리드를 적용했다. 숫자 키패드의 네 행은 남은 높이를 균등 분배하므로 발문이나 피드백 영역으로 넘어가지 않는다.

## 남은 제한사항

- 실제 iPhone Safari 렌더링은 현재 도구 환경에서 직접 캡처하지 못했다.
- 스킨은 별도 고해상도 원화가 아니라 기존 캐릭터 이미지에 CSS 레이어를 적용한다.
- 다른 기기 간 보유 상품 동기화를 하려면 로그인과 서버 저장소가 필요하다.
