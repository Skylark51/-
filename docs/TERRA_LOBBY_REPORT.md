## 제거한 가짜 데이터와 로비 동작

- 점수 추이의 고정 fallback 배열을 제거했다.
- 완료된 실제 recentRuns가 없으면 그래프 대신 다음 빈 상태를 표시한다.
  - 아직 플레이 기록이 없습니다. 첫 장독대를 채우면 점수 그래프가 생성됩니다.
- 기록이 한 개면 선 그래프 대신 해당 점수와 시간을 단일 기록으로 표시한다.
- 장독대별 정답률은 실제 플레이 또는 답안 기록이 있는 장독대만 표시한다.
- 미도전 장독대를 0% 정답률로 표시하지 않는다.
- 기존 로비의 ui-effects.js 초기화를 로드하지 않는다. 게임 화면의 해당 모듈은 그대로 사용한다.
- 빠른 퀴즈, 두꺼비 연구소, 환영 카드 버튼은 모두 실제 동작을 수행한다.

대시보드는 총 플레이, 전체 정답률, 최고 콤보, 보유 콩, 평균 반응 시간, 가장 많이 틀린 장독대, 최근 플레이 일시와 최근 8회 완료 점수를 실제 저장 데이터에서 계산한다.

## 빠른 퀴즈 선택 규칙

1. 답안 기록에서 오답 또는 시간 초과가 있는 장독대 중 오답률이 가장 높은 장독대를 선택한다.
2. 약점 기록이 없고 저장된 진행 중 게임이 있으면 해당 장독대를 이어서 시작한다.
3. 기록이 없으면 원자 번호, 원자량, 주기와 족, 원자가 전자 중 가장 적게 플레이한 입문 장독대를 선택한다.
4. 기본 난도는 저장된 난도를 사용한다. 모드가 지원하지 않는 값이면 해당 모드의 권장 난도로 안전하게 대체한다.
5. 빠른 퀴즈와 메인 CTA 모두 한 번의 탭으로 게임 화면으로 이동한다.

메인 CTA는 진행 중 게임이 있으면 이어서 채우기, 기록이 있으면 약점 또는 빠른 퀴즈 시작, 첫 방문이면 원자 번호부터 시작으로 바뀐다.

## 오늘의 미션

저장 버전을 4로 올리고 기존 저장 데이터를 보존하는 migration을 추가했다.

dailyMission 필드:
- date: YYYY-MM-DD
- type: correct_answers 등의 미션 유형
- target: 목표 수
- progress: 실제 진행도
- rewardBeans: 보상 콩
- claimed: 중복 수령 방지 상태

- 날짜가 바뀌면 로컬 날짜 기준으로 새 미션을 결정적으로 생성한다.
- 후보: 정답 수, 피버 발동, 콤보 5 달성, 장독대 완료, 2초 이내 정답, 물 100% 도달.
- 진행은 기존 게임이 이미 호출하는 저장 메서드에서 집계한다.
  - 답안 기록
  - 피버 시작
  - 현재 게임 저장의 콤보 및 물 수치
  - 완료된 장독대 상태
- 완료 전 보상 버튼은 비활성화된다.
- 수령 후 claimed를 먼저 저장하고 콩을 지급하므로 중복 수령할 수 없다.
- 콩 수령 직후 대시보드와 연구소 잔액을 다시 렌더링한다.

## 두꺼비 연구소 연결

기존 data/upgrades.js의 가격, 최대 레벨, 효과값을 변경하지 않았다.

연구소는 다음 여섯 가지를 실제 UpgradeSystem으로 구매한다.

- 바가지
- 숟가락
- 장독대
- 두꺼비 방어구
- 피버
- 물의 힘

각 카드에는 현재 레벨, 최대 레벨, 현재 효과, 다음 레벨 효과, 가격과 구매 상태를 표시한다. 콩 부족과 최대 레벨은 버튼 문구와 카드 상태로 함께 구분한다. 구매 중 현재 버튼을 즉시 비활성화하고, 성공·실패 결과를 aria-live 영역에 알린다.

## 모바일 및 접근성

- 로비 전용 CSS를 assets/css/lobby-dashboard.css로 분리했다.
- 모바일 하단 도구막대는 고정하고 safe-area 및 콘텐츠 하단 여백을 반영했다.
- 첫 화면의 CTA는 최소 48px 터치 높이를 가진다.
- 320×568, 360×640, 390×844, 412×915를 위한 700px, 360px, 650px 이하 반응형 규칙을 추가했다.
- 로비는 스크롤 가능하며 상세 기록은 접힌 상태로 시작한다.
- 그래프는 viewBox, title, aria-label을 사용하며 모바일에서도 너비가 잘리지 않도록 한다.
- 아이콘 버튼, 하단 탐색, 다이얼로그 제목, 미션·연구소 결과 영역에 접근성 속성을 적용했다.

이 환경에는 로컬 브라우저 자동화 런타임이 없어 실제 스크린샷 기반 검사는 실행하지 못했다. 반응형 확인은 CSS 계약과 자동 테스트로 수행했다.

## Terra 2 확인 사항

- 로비는 기존 kongjuiya-training-selection 세션 키와 trainingId, difficulty, resume 구조를 그대로 사용한다.
- assets/js/main.js 및 모바일 키패드 파일은 변경하지 않았다.
- 일일 미션의 콤보·물 100% 집계는 기존 main.js가 답안 처리 후 호출하는 saveCurrentRun(game.snapshot())의 bestCombo, water 값을 이용한다.
- 게임 화면 또는 키패드 변경 시 이 두 상태 필드를 유지해야 미션 진행이 계속 정확하게 반영된다.

## 알려진 제한사항

- 완료되지 않은 진행 중 게임은 대시보드의 최근 완료 점수 그래프에 포함하지 않는다. 이는 가짜 점수 대신 완료 기록만 보여 주기 위한 의도된 동작이다.
- 브라우저 자동화 런타임이 제공되지 않아 실제 기기 화면 캡처는 이 작업 환경에서 수행하지 못했다.
- 기존 키패드 CSS 마커 테스트 실패는 이번 로비 변경과 독립적이며, 담당 파일이 아니므로 변경하지 않았다.
