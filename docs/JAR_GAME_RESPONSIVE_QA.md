# 장독대 반응형 QA

PC는 장면과 문제의 좌우 구조다. 모바일 세로는 HUD → 장면 → 문제/키패드이며 게임 하단 앱 툴바가 없다. 모바일 가로는 장면과 입력을 좌우 배치한다.

`device-entry.js`는 visualViewport를 우선해 높이·너비·화면비·방향·short/compact/tall·narrow/phone/wide 상태를 설정한다. resize와 orientation 이벤트는 한 RAF로 합친다.

모바일 숫자 키패드는 항상 3열이다.

1 2 3
4 5 6
7 8 9
0 ⌫ 전체
제출 전체 너비

문제 카드와 키패드는 독립 grid 행이다.

정적 대상: 320×568, 360×640, 375×667, 390×844, 412×915, 430×932, 모바일 가로, 1280×720, 1366×768, 1440×900, 1920×1080.

실제 iPhone Safari 육안 검수는 배포 후 필요하다.
