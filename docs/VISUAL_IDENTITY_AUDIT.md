# 시각 정체성 감사

## 감사 기준

기준 브랜치: `main`의 `05869b1` 이후 상태. 공식 제목은 `콩쥐야 줘때써 - 화학편`으로 고정한다. 화학 문항, 정답 판정, 점수·물 규칙, 저장 데이터 의미는 감사 대상에서 제외했다.

## 확인된 문제

1. 로비는 연보라색 학습 대시보드, 게임은 실사 장면, 상점은 SVG 스프라이트로 구성되어 한 제품처럼 보이지 않았다.
2. `game.css`, `lobby-dashboard.css`, `shop.css`, `cosmetics.css`가 각각 별도 색·반경·그림자를 정의해 같은 버튼과 카드가 화면마다 달랐다.
3. 로비 모바일 하단 메뉴가 앵커 스크롤을 사용해 앱 탭처럼 동작하지 않았다.
4. 로비에는 빠른 메뉴, 대시보드, 상세 기록이 한 문서에 길게 이어져 정보 구조가 불명확했다.
5. 기본 실사 장면은 네 개의 PNG 핵심 포즈를 브라우저에서 보간해 60셀 아틀라스로 만드는 방식이다. 60장의 독립 원화가 아니다.
6. 실사 렌더러가 켜지면 기존 스킨 DOM이 숨겨져 구매 외형이 게임에 반영되지 않는 충돌이 있었다.
7. 상점 미리보기는 실제 스킨 데이터와 연결되어 있었으나 로비·게임의 실사 톤과 재질감이 달랐다.
8. 큰 인라인 모바일 보정 규칙과 여러 렌더러가 공존해 수정 시 회귀 위험이 높았다.

## 유지할 핵심

- `GameStorage`, 저장 버전 4 및 마이그레이션
- `QuestionEngine`, 훈련 모드와 화학 데이터
- 실제 기록만 표시하는 대시보드 로직
- 기존 구매·보유·장착 데이터
- 장독대 테마, SVG 스킨 시트, 기본 실사 PNG 핵심 포즈
- `visualViewport` 기반 모바일 게임 레이아웃

## 통합 방향

- 공통 토큰: `assets/css/design-system.css`
- 화면별 오버라이드: `assets/css/unified-identity.css`
- 공통 런타임: `assets/js/identity-runtime.js`
- 로비 앱 탭: `assets/js/lobby-navigation.js`
- 기본 장착 세트는 실사 핵심 포즈 렌더러를 사용한다.
- 비기본 스킨 장착 시 실제 구매 자산을 보여 주기 위해 스프라이트 렌더러로 전환한다.
- 이 전환은 최종 자산 파이프라인이 아니라, 스킨 미반영을 막기 위한 명시적인 과도기 구조다.
