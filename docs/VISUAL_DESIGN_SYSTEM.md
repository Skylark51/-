# 시각 디자인 시스템

## 콘셉트

`고해상도 한국 전래동화풍 모바일 아케이드 게임`

현대적인 앱 구조를 사용하되 한지, 옹기, 나무, 청자, 물, 금색 보상이라는 재료 언어를 전 화면에서 공유한다. 범용 학습 앱의 연보라색을 주요 색에서 제거하고, 먹색과 옹기 갈색을 중심으로 청자색을 조작 색상으로 사용한다.

## 핵심 토큰

- 배경: `--paper-50`, `--paper-100`, `--paper-200`
- 본문: `--ink-950`부터 `--ink-500`
- 옹기: `--onggi-950`부터 `--onggi-500`
- 청자: `--celadon-800`부터 `--celadon-500`
- 물: `--water-700`부터 `--water-300`
- 보상: `--gold-700`부터 `--gold-300`
- 성공·실패: `--success-*`, `--danger-*`
- 반경: `--radius-sm`부터 `--radius-xl`
- 그림자: `--shadow-1`부터 `--shadow-3`
- 안전 영역: `--safe-top`, `--safe-bottom`

## 공통 컴포넌트

- 상단 바: 한지색 반투명 표면과 얇은 옹기색 테두리
- 기본 버튼: 청자색 그라데이션
- 보조 버튼: 한지색과 옹기색 글자
- 위험 버튼: 옅은 적갈색 배경
- 콩 지갑: 금색 원형 표식과 실제 저장 잔액
- 카드: 한지색 표면, 낮은 그림자, 18~26px 반경
- 하단 탭: 홈·장독대·기록·상점 4개로 통일
- 제목: 명조 계열, 본문과 조작 요소: 고딕 계열

## 반응형 원칙

PC와 모바일은 배치만 달라지고 색·타이포그래피·컴포넌트는 동일하다. 모바일 로비는 탭 전환이며 자동 스크롤을 사용하지 않는다. 게임 화면은 기존 `visualViewport` 계산과 3열 숫자 키패드를 유지한다.
