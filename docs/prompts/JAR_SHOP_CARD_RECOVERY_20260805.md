# 장독대 상점 카드 복구 프롬프트

업로드된 모바일 장독대 스킨 화면을 기준으로 `KongJuiYa_Chem`의 장독대 상품 카드만 수정한다.

## 확인된 문제

- 장독대 PNG의 상반부만 보이고 몸통과 구멍이 잘린다.
- 직전 수정에서 이미지 침범을 막기 위해 `overflow: hidden`을 적용했지만, 카드의 이미지 행 높이는 약 80px 수준으로 남아 있어 이미지가 잘린다.
- 모바일 상품 그리드가 남는 세로 공간을 행 사이의 큰 공백으로 소비한다.
- 구매·장착 버튼 위치는 카드 하단에 있어야 하며 장독대 이미지와 절대 겹치면 안 된다.

## 수정 목표

1. 네 장독대 PNG의 전체 형태와 구멍이 모두 보여야 한다.
2. 이미지는 왜곡하지 말고 `object-fit: contain`과 중앙 정렬을 사용한다.
3. 모바일 장독대 카드는 이미지 행에 충분한 고정 높이를 배정한다.
4. 카드 높이를 확보하되 2열 구조를 유지하고, 두 카드 행 사이의 과도한 빈 공간을 제거한다.
5. 상품명·희귀도·가격은 이미지 아래에 위치한다.
6. 구매·장착 버튼은 카드 최하단에 고정하고 이미지와 겹치지 않게 한다.
7. 장독대 외의 의상·도구·두꺼비 화면은 변경하지 않는다.
8. 작은 화면에서는 카드 그리드를 세로 스크롤 가능하게 하되 장독대 전신을 자르지 않는다.
9. 회귀 테스트를 갱신해 이미지 행 최소 높이, 카드 높이, 버튼 하단 고정, `object-fit: contain`을 검증한다.
10. 작업 후 `main`에 커밋하고 푸시한다.
