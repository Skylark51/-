# 원자 번호 장독대 초단문 출제 + 시작 카운트다운 수정 프롬프트

## 문제 확인

원자 번호 장독대는 빠르게 원소 기호를 보고 원자 번호를 입력하는 암기형 훈련이다. 현재 문항이 `원소 기호 Al의 원자 번호는?`처럼 완전한 문장으로 표시되어 시선 이동과 읽기 시간이 불필요하게 늘어난다. 이 모드에서는 이미 상단에 `원자 번호 장독대`라는 맥락이 노출되므로 문제 본문에는 원소 기호만 표시하는 편이 적합하다.

또한 페이지에 들어오자마자 게임 타이머와 누수가 시작되면 플레이어가 화면을 인지하고 손을 올릴 준비 시간이 없다. 원자 번호 장독대에 처음 진입할 때는 실제 게임 시작 전에 짧은 준비 구간이 필요하다.

## 해결 목표

1. `atomic_number`의 모든 문제 본문은 `H`, `He`, `Al`, `Ca`처럼 원소 기호만 표시한다.
2. 답, 해설, 태그, 키패드 입력 방식, 난이도와 채점 규칙은 변경하지 않는다.
3. 원자 번호 장독대 최초 진입 시 게임 엔진의 `api.start()`보다 먼저 준비 오버레이를 연다.
4. 준비 오버레이에는 정확히 `자... 숨 고르시고.. 시작합니다`를 먼저 보여준다.
5. 그 다음 `3 → 2 → 1 → 시작`을 순서대로 보여주고 오버레이가 자연스럽게 사라지면서 게임 화면을 연다.
6. 카운트다운 동안에는 게임 상태가 `idle`이어야 하며 문제 제한시간과 장독대 누수가 감소하면 안 된다.
7. 재시작 버튼으로 같은 장독대를 다시 시작할 때는 이 최초 진입 카운트다운을 다시 강제하지 않는다.
8. 다른 장독대의 기존 시작 흐름은 변경하지 않는다.
9. 원자 번호처럼 매우 짧은 문제는 문제 카드 중앙에서 큰 글자로 즉시 인식되도록 한다.
10. 모바일 367×662 화면에서 오버레이와 키패드 레이아웃이 깨지지 않아야 한다.

## 구현 지시

- `data/questions/atomic-number.js`의 prompt를 문장 대신 `symbol` 자체로 변경한다.
- 변경된 문항 모듈이 브라우저의 이전 모듈 캐시에 묶이지 않도록 `data/questions/index.js`, `data/questions.js`, `assets/js/main.js`, `assets/js/ui-effects.js`, 게임 HTML의 관련 query version을 갱신한다.
- `assets/js/ui-effects.js`에 `atomic_number` 전용 최초 진입 카운트다운을 구현한다.
- 장면 렌더러가 준비된 뒤 카운트다운을 시작하고, 카운트다운이 끝난 다음에만 `api.start({ difficulty, resumeState })`를 호출한다.
- 기존 `#startOverlay`와 숨겨진 시작/난이도 컨트롤은 삭제하지 말고 카운트다운 표시용 요소를 추가해서 재사용한다.
- `assets/css/atomic-number-speed-start.css`에서 원자 기호용 대형 타이포그래피와 전체 화면 준비 오버레이를 정의한다.
- 정적 회귀 테스트에서 symbol-only prompt, 정확한 준비 문구, 3/2/1 순서, `runOpeningCountdown`이 `api.start`보다 먼저 호출되는지, cache-bust wiring을 검증한다.
- 기존 367×662 Playwright smoke에서도 실제 원자 번호 문제 본문이 원소 기호 한 개만 표시되는지 확인한다.

## 완료 조건

- `Al` 문제는 화면에 `Al`만 표시된다.
- 진입 직후 `자... 숨 고르시고.. 시작합니다`가 보인다.
- 이어서 3, 2, 1이 표시된다.
- 카운트다운이 끝난 뒤에만 문제 타이머와 누수가 시작된다.
- 원자 번호 문제의 답안/채점은 기존과 동일하다.
- 다른 훈련 모드는 기존처럼 즉시 시작한다.
- 367×662 브라우저 smoke와 정적 회귀 테스트가 모두 통과한다.
- 수정 사항을 main에 커밋·푸시한다.
