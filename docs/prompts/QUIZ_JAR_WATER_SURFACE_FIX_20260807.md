# 퀴즈 장독대 물 표현 통합 수정 프롬프트

## 확대 캡처에서 확인된 문제

두꺼비 자체의 검은 타원 문제는 해결되었지만, 청자 장독대 전면에 큰 청색 반투명 영역이 남아 있다. 이 영역은 장독대 내부의 물이 아니라 외벽 위에 붙은 사각형/다각형 필터처럼 읽힌다.

원인은 `scene-water-fill` 레이어가 장독대 몸통의 넓은 영역에 배치되고, polygon clip으로 장독대 내부 전체를 채우도록 설계되어 있기 때문이다. 청자와 흑칠처럼 authored 2-layer jar를 사용할 때 이 레이어가 `jar-back`과 `jar-front` 사이에 있으므로 외벽의 문양과 질감을 청색으로 덮어 버린다.

특히 모바일 확대 화면에서 다음이 명확하다.

1. 청색 수면이 장독대 입구가 아니라 몸통 전면에 보인다.
2. 물 레이어가 거의 직사각형/방패형으로 보여 도자기 표면에 붙은 UI 패널처럼 보인다.
3. 청자 문양이 물 레이어에 의해 가려져 원본 PNG 품질이 훼손되어 보인다.
4. 물 수위는 상단 HUD에 이미 수치로 표시되므로, 장독대 외벽 전체를 색으로 채울 필요가 없다.
5. 실제 불투명한 옹기/도자기에서는 내부 물은 입구에서만 보이는 것이 자연스럽다.

## 해결 원칙

- 기존 장독대 PNG와 물 texture PNG는 수정·리사이즈·재압축하지 않는다.
- 물 수위 데이터와 게임 로직은 유지한다.
- `scene-water-fill`을 장독대 몸통에서 제거하고 **장독대 입구 안쪽의 작은 수면 viewport**로 재배치한다.
- 수면은 타원형으로 제한한다.
- `--scene-water-level`은 기존과 동일하게 사용해 0%에서는 보이지 않고, 수위가 올라갈수록 입구 내부에서만 물이 차오르게 한다.
- 청자/흑칠 등 authored jar마다 입구 좌표를 미세하게 보정한다.
- 물 표면은 `jar-back` 위, `jar-front` 아래 레이어 순서를 유지한다.
- 외벽 문양과 두꺼비 영역은 물 레이어가 절대 덮지 않게 한다.

## 구현 지시

1. `assets/css/jar-water-surface-fix.css`를 새 최종 override 레이어로 만든다.
2. `.scene-water-fill`의 기존 body-size polygon clip을 무효화한다.
3. 기본 수면 viewport를 대략 장면 기준 x 66~68%, y 30~34%, width 13~16%, height 6~9% 범위의 입구에 배치한다.
4. clip-path는 ellipse를 사용하고 border-radius 50%를 적용한다.
5. 내부 `.scene-water-fill-texture`는 bottom 기준으로 기존 `--scene-water-level` 높이를 사용한다.
6. 외벽에 보이는 큰 파란 면적을 만들 수 있는 box-shadow, filter, 큰 border를 사용하지 않는다.
7. `celadon`과 `night-lacquer`에 별도 입구 위치 값을 둔다.
8. 모바일 367×662 회귀 테스트에서 다음을 검사한다.
   - water-fill 폭이 jar 폭의 50% 미만
   - water-fill 높이가 jar 높이의 20% 미만
   - water-fill 중심이 jar 상단 45% 이내
   - water-fill이 두꺼비 영역과 겹치지 않음
   - clip-path가 ellipse
   - 페이지 overflow/콘솔 오류 없음
9. CI workflow가 새 CSS와 회귀 테스트 변경을 추적하도록 한다.

## 완료 조건

- 확대 화면에서 장독대 외벽의 큰 청색 패널이 사라진다.
- 물은 장독대 입구 안쪽에서만 보인다.
- 청자 원본 문양이 가려지지 않는다.
- 기존 물 수위 값은 정상적으로 변한다.
- 두꺼비와 물이 서로 겹치지 않는다.
- 367×662 브라우저 회귀 테스트와 기존 layered scene 테스트가 모두 통과한다.
