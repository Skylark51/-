# 퀴즈 장독대 두꺼비 구멍 합성 수정 프롬프트

## 기준 캡처

사용자가 확대해서 제공한 장독대/두꺼비 부분 캡처를 기준으로 한다. 새 이미지를 생성하지 않고 현재 저장소의 장독대 PNG와 두꺼비 PNG를 그대로 사용한다.

## 캡처에서 확인된 문제

1. 두꺼비 주위에 큰 검은 타원형 면이 노출되어 실제 구멍이 아니라 검은 스티커를 붙인 것처럼 보인다.
2. 검은 면의 크기가 두꺼비보다 훨씬 커서 시선이 캐릭터가 아니라 검은 원에 먼저 간다.
3. 두꺼비는 그 검은 면 안에서 상대적으로 작아 보이며, 장독대를 막고 있다는 상황이 잘 전달되지 않는다.
4. 구멍 경계가 완벽한 타원에 가까워 도자기 파손부나 장독대 내부 공간처럼 보이지 않는다.
5. 장독대 앞면과 두꺼비 사이의 깊이감이 약하다. 두꺼비가 장독대 내부에 들어가 있기보다 전면에 겹쳐 붙은 것처럼 보인다.
6. 청자/옹기/달항아리/흑칠 장독대가 서로 다른 재질인데도 동일한 순흑색 cavity를 사용하면 합성 티가 강해진다.

## 수정 목표

- 검은 타원형 판을 제거한다.
- 두꺼비 PNG 자체는 원본 비율과 색을 유지한다.
- 구멍 내부의 어둠은 완전한 검정 면이 아니라 작고 부드러운 radial cavity로만 표현한다.
- cavity는 두꺼비보다 조금만 크게 만들고 가장자리를 투명하게 페더링한다.
- 장독대 재질별로 cavity의 색조를 미세하게 다르게 한다.
- 두꺼비는 현재보다 약간 확대해 얼굴과 몸통이 즉시 식별되게 한다.
- 두꺼비 레이어의 바깥 상자는 줄이되 PNG 내부 이미지는 확대하여, 검은 구멍은 작아지고 캐릭터는 더 커져 보이게 한다.
- 레이어 순서 `jar-back → toad → jar-front`를 유지하여 장독대 앞면이 두꺼비의 하단/가장자리를 자연스럽게 가리도록 한다.

## 구현 규칙

### 두꺼비 wrapper

- `scene-toad-skin`, `scene-toad-expression` 자체의 `background`는 반드시 `none/transparent`로 한다.
- wrapper 전체를 어두운 색으로 채우지 않는다.
- 완벽한 검은 ellipse를 금지한다.

### 내부 cavity

- `::before`에 작은 radial-gradient cavity를 만든다.
- cavity 크기는 wrapper보다 확실히 작아야 한다.
- 중심부도 순수 `#000`을 사용하지 않는다.
- 외곽은 transparent로 사라져야 한다.
- `::after`의 인공 테두리/검은 링은 제거한다.

### 두꺼비 확대

- 모바일에서 wrapper 폭은 장면 폭의 약 12~14% 수준으로 줄인다.
- `skin-only` PNG는 약 1.4~1.5배 확대한다.
- `full-fallback` 표정 PNG는 약 2.3~2.5배 확대한다.
- 확대는 원본 PNG를 재인코딩하거나 리사이즈 파일을 만드는 방식이 아니라 CSS transform만 사용한다.

### 장독대별 cavity 색감

- 옹기: 짙은 갈색 계열
- 청자: 어두운 녹회색 계열
- 달항아리: 중성 회갈색 계열
- 흑칠: 흑갈색 계열

모두 지나치게 밝거나 선명하게 만들지 않는다.

## 회귀 검사

367×662 실제 모바일 브라우저 테스트에서 다음을 확인한다.

1. 두꺼비 wrapper의 computed `background-image`가 `none`이다.
2. wrapper 배경색은 투명하다.
3. 작은 cavity용 `::before`에 radial-gradient가 존재한다.
4. 인공 외곽링 `::after`는 표시되지 않는다.
5. 두꺼비 wrapper 폭은 장면 폭의 11~15% 이내다.
6. 실제 두꺼비 PNG는 wrapper보다 확대되어 표시된다.
7. 두꺼비가 장면 밖으로 잘리지 않는다.
8. 기존 퀴즈 입력, 점수, 피버, 저장, 장착 기능은 그대로 동작한다.
9. 기존 layered scene 및 실제 gameplay smoke test가 모두 통과한다.

## 금지 사항

- 신규 두꺼비/장독대 이미지 생성 금지
- PNG 재압축/재인코딩 금지
- WebP 변환 금지
- CSS hue-rotate/sepia 기반 스킨 변경 금지
- 검은 원 또는 검은 타원으로 구멍을 통째로 채우는 방식 금지
