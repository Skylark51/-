# 통합 장독대 앱 보고서

## 원인
기존 메인은 연보라색 학습 대시보드, 게임은 어두운 실사풍으로 분리돼 하나의 제품처럼 보이지 않았다. 게임 장면은 2×2 키포즈 이미지를 CSS 배경 좌표로 잘라 사용하면서 화면 비율에 따라 얼굴 조각과 검은 영역만 노출됐다.

## 수정
- 메인·장독대 선택·기록·게임을 먹색, 옹기색, 한지색, 물빛, 금색의 전래동화 아케이드 체계로 통일
- 모바일 메인은 홈·장독대·기록 화면을 실제 앱 탭처럼 전환
- 게임은 CSS 배경 좌표 크롭을 제거하고 canvas 기반 단일 SceneRenderer로 교체
- 기존 2×2 PNG의 각 핵심 포즈를 정확한 원본 셀 좌표로 잘라 canvas에 비율 보존 렌더링
- 메인 대표 장면도 같은 원본의 idle 셀을 사용
- 정답, 오답·시간 초과·게임 오버, 클리어 상태를 실제 존재하는 핵심 원화에 연결
- 모바일 320×568, 390×844, 412×915 및 가로 844×390에서 한 화면 배치와 3열 키패드 검사

## 애니메이션의 정확한 범위
현재 자산은 60장의 연속 프레임이 아니다. 실제 원화는 idle, pour, wrong 계열, clear의 4개 핵심 포즈다. 상태 전환 시 canvas 교차 표시와 물·누수 효과를 사용하며, 위치만 이동한 복제 이미지를 60프레임이라고 표기하지 않는다.

## 스킨
기존 구매 기록은 유지한다. 고품질 상태 원화가 없는 비기본 스킨은 색상 필터로 위장하지 않고, 원화 준비 중 안내와 기본 실사 장면을 표시한다.
