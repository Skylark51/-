ABOUT THE GAME

문제를 풀어 새는 장독대를 채우는 화학 게임

콩쥐야 줘때써 - 화학편은 짧은 문제 풀이와 즉각적인 장면 반응을 연결한 오리지널 브라우저 게임입니다. 정답을 맞힐수록 물을 채우고, 두꺼비가 막고 있는 구멍을 지켜냅니다.

장독대 고르기

핵심 게임 루프

  1. 원하는 장독대를 골라 화학 개념 하나에 집중합니다.
  2. 문제를 읽고 키보드·화면 키패드·선택지로 답합니다.
  3. 정답으로 물과 점수를 얻고, 빠른 연속 정답으로 콤보와 피버를 쌓습니다.
  4. 물 수위를 지키며 목표를 달성하면 해당 장독대를 채웁니다.

물 수위와 남은 시간은 단순한 장식이 아니라 매 문제의 판단 속도와 정확도를 보여 주는 게임 상태입니다.

장독대와 두꺼비

각 장독대는 원자 구조, 주기적 성질, 화학 반응처럼 하나의 주제를 뜻합니다. 두꺼비는 장독대 구멍을 막으며 플레이 상황에 반응하고, 콩쥐는 정답을 맞힐 때 물을 붓습니다. 게임 화면의 변화는 현재 수위·콤보·피버 상태를 읽기 쉽게 돕기 위한 것입니다.

이 프로젝트는 독립적으로 제작·운영되는 오리지널 학습 게임입니다. 문항과 게임에서 사용하는 값은 프로젝트의 출제 기준에 따라 관리됩니다.
